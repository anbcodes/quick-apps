Quick Apps

Small desktop apps you install from a link. Each app is a WebAssembly file, usually a few kilobytes, that runs in its own sandbox and updates from the URL it came from.

curl -fsSL https://…/install.sh | sh

Linux (Wayland), x86_64. Puts one 4 MB binary at ~/.local/bin/qa and makes qa: links open with it. No root needed.

Try an app

Install the runtime first, then click Install. Your browser asks once whether to open qa links. After that, each app shows what it is and where it's from, and waits for you to confirm.

How it works

A link is the installer

An app is a manifest and a zip file on any static host. Installing adds it to your app menu and gives it a command name in your terminal.

Nothing by default

Apps get their own folder and nothing else. Internet, other folders, and extra memory or CPU each need your permission, asked by the runtime and not by the app.

Updates from the source

When an app starts, it checks its URL for a newer version and offers to update. The previous version is kept, so qa rollback can go back.

Publish your own

Write the app in Rust with qa-sdk (or any language that compiles to WebAssembly), then pack it:

qa dev ./notes              # build, run, reload on save
qa pack ./notes --out dist  # writes notes-1.0.0.zip and app.json

Upload both files anywhere that serves HTTPS and link to the manifest:

<a href="qa:https://example.com/notes/app.json">Install Notes</a>

To set up the runtime and an app in one step, pass the manifest to the install script:

curl -fsSL https://…/install.sh | sh -s -- https://example.com/notes/app.json
